# Product brief — /hub-init 2026-11-08 (khajonpot)

Mode: new project. Language: English. Docs owner and business-rule decider: khajonpot.

Users: engineers and architects on software teams.

Purpose: A tool for software teams to create, version and share architecture diagrams
(system/container/component views) as code or via a visual editor, kept in sync with the
real system.

On top of that, it is about everything that can describe an end-to-end (E2E) architecture,
which consists of various projects and integrations. Example: on cloud such as AWS there is
an application running in EKS; it requires AWS RDS Postgres to run, and it also requires some
API from an on-prem application which must be accessed via the landing zone to connect to
on-prem. So from the point of view of an application, the tool should show dependency and
linkage, and with this, when we have a CR (change request) to some application, we can see
the impact on the whole chain.
